# Folder Pins — Codex 风格的文件浏览器分区

给 Obsidian 核心文件浏览器(左侧栏文件列表)加上类似 Codex 侧栏的分区能力:
顶部"置顶"区域 + 其余文件夹/文件,支持拖动排序。

## 功能

- **置顶**:右键任意文件/文件夹 → 「置顶」;置顶项集中到顶部"置顶"区域(带图钉标记)。
- **取消置顶**:右键已置顶项 → 「取消置顶」,或直接把它拖回下方区域。
- **拖动排序**:悬停任意行,行尾出现 ⠿ 手柄,按住手柄拖动即可排序。
  - 区内拖动 = 调整顺序;
  - 跨过分界线(向上/向下)= 置顶 / 取消置顶(Codex 交互);
  - 行间会出现高亮插入线指示落点;拖到列表边缘自动滚动。
- **持久化**:置顶列表与顺序保存在本插件 `data.json`,随仓库同步,重启不丢。
- 原生拖拽不受影响:不通过手柄发起的拖拽(如把文件拖进笔记嵌入)仍走 Obsidian 原逻辑。

## 命令(命令面板搜 Folder Pins)

- `置顶/取消置顶:当前文件所在文件夹`
- `清除根目录手动排序(保留置顶)` — 恢复默认排序规则,置顶不受影响

## 说明

- 手动排序一旦建立(第一次拖动后),根目录的顺序由该排序接管;
  原生排序菜单(名称/修改时间等)不再影响根目录,直到执行上面的清除命令。
- 分区标题"置顶"吸附在顶部随滚动固定。
- 已验证环境:Obsidian 1.14.4(Windows)。要求 1.11+。

## 卸载 / 关闭

在 设置 → 第三方插件 中禁用 Folder Pins 即可完全恢复原生文件浏览器(禁用时会自动清理注入的样式与手柄)。
